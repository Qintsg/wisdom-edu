# 演示数据导入说明

> 本文档说明如何导入基础测试账号、班级关系、课程资产和 student1 大数据桌面快照演示状态。

## 快速开始

```bash
cd backend

# 方式一：初始化数据库、创建基础账号/课程/班级，并自动导入课程资产、同步 Neo4j / GraphRAG
uv run python tools.py pg-bootstrap

# 兼容下划线写法
uv run python tools.py pg_bootstrap

# 方式二：仅创建基础测试数据，不清空已有数据
uv run python tools.py create-test-data

# 方式三：单独导入课程资产
uv run python tools.py bootstrap-course-assets --course-name 大数据技术与应用

# 方式四：只重放桌面导出的 student1 大数据演示快照
uv run python tools.py preset-student1-demo-snapshot
```

## 默认班级与课程上下文

- `create-test-data` 会读取 `backend/tools/testdata.json5`，创建基础账号、课程壳、班级、邀请码和学生默认入班关系。
- 所有学生会按配置加入班级，并把默认课程上下文设置为 `大数据技术与应用` 对应课程和班级。
- `student1` 仍额外加入所有基础班级，方便本地验证多班级课程选择和切换逻辑。
- 班级邀请码来自 `backend/tools/testdata.json5` 的 `class_invitations`，学生端可在“我的班级”或“个人设置”中输入邀请码加入班级。

## 课程资产来源

`大数据技术与应用` 的知识点、题库、资源、作业库等课程内容统一来自：

```text
backend/tools/自适应学习系统-课程资源
```

导入入口为：

```bash
cd backend
uv run python tools.py bootstrap-course-assets --course-name 大数据技术与应用
```

基础种子只负责创建课程壳、账号、班级、邀请码和默认关系。`testdata.json5` 中保留的课程内容片段不会再为 `大数据技术与应用` 额外生成重复知识点、题库或资源。

课程资产导入会在知识图谱、题库、PPT、教学视频和电子教材写入后自动补齐题目/资源与知识点的绑定。导入完成后，初始测评题目、可见题库和课程资源应直接具备可供 MEFKT、路径生成、画像刷新和 RAG 检索使用的知识点关系。

## student1 桌面演示快照

`pg-bootstrap` 和 `bootstrap-course-assets --course-name 大数据技术与应用` 在课程资源导入收尾时，会尝试读取当前用户桌面上的三份导出页面：

```text
测评报告 - 自适应学习系统.html
学习画像 - 自适应学习系统.html
学习路径 - 自适应学习系统.html
```

同时会解析同名 `_files` 资源目录，记录资源文件数量和总大小到课程配置。若文件存在，系统会为 `student1` 的 `大数据技术与应用` 写入：

- 初始知识测评结果：80 分、答对 40 / 50 题，并保留 50 道题的作答明细。
- 初始答题历史：来源标记为 `initial`，用于后续 MEFKT、学习路径和画像刷新读取。
- 知识点掌握度：优先使用测评报告页面解析出的掌握度，必要时补齐报告中存在但当前课程缺少的演示知识点。
- 能力分、学习习惯和画像摘要：来自学习画像页面的可见文本。
- 初始学习路径：9 个节点，完成进度预置到 `Spark SQL原理与特征基础`，下一节点为 `大数据系统实践基础`。

可单独重放该快照，不必重新清库或重新导入课程资产：

```bash
cd backend
uv run python tools.py preset-student1-demo-snapshot
```

如果桌面导出文件不在默认桌面目录，可显式传入目录：

```bash
uv run python tools.py preset-student1-demo-snapshot --desktop-root "C:\Users\qintsg\Desktop"
```

## 常用验证命令

```bash
cd backend
uv run python tools.py db-check
uv run python tools.py django-check
uv run python tools.py preset-student1-demo-snapshot --dry-run
uv run python tools.py browser-audit --scenario audit --frontend-url http://127.0.0.1:3000 --api-base-url http://127.0.0.1:8000
```

普通浏览器巡检场景只保留 `audit`、`prepare-demo` 和 `simulate-demo`。如需课程资产、题库或 GraphRAG 索引重新生成，应使用 `bootstrap-course-assets`、`build-rag-index` 或 `refresh-rag-corpus` 等真实业务命令。

## 不再预置的内容

- 不再提供旧答辩脚本式的固定阶段测试反馈、固定知识点介绍或固定 AI 回答。
- 不再提供额外的课程导入压缩包生成命令。
- 不再写入旧答辩轨迹；`student1` 仅保留从桌面导出页面解析出的初始评测、画像掌握度和学习路径快照。
- 不再提供固定浏览器讲解链路；学生端流程应通过真实初始评测、课程学习、问答和作业提交产生数据。
